# 🍲 Chibugbog POS System

A lightning-fast, zero-overhead Point of Sales (POS) system designed for Chibugbog restaurant. This entire enterprise web application is built strictly as a serverless tool contained completely within a single `index.html` file for instant local execution and global cloud deployment.

## 🛠️ Tech Stack & Constraints
This project is built under strict architectural constraints to maximize loading speed and eliminate hosting costs:
*   **Structure:** HTML5 Semantic elements
*   **Styling:** Tailwind CSS (Injected instantly via production CDN)
*   **Logic:** Vanilla JavaScript (ES6+, zero runtime frame dependencies)
*   **Deployment:** GitHub Pages (Static hosting engine)

---

## ✨ Features
*   **Single-File Architecture:** UI structure, responsive design styles, layout, and state logic coexist inside one `index.html` asset.
*   **Zero Build Pipelines:** No compilation required. No `node_modules`, no Webpack, no Vite, and no configuration files.
*   **Reactive State Engine:** Real-time synchronization between the local menu configuration array and the client-side cart totals checkout drawer.
*   **Automated Accounting:** Instant local adjustments computing item quantities, base currency subtotal sums, localized 12% VAT matrices, and total balances.
*   **Responsive Blueprinting:** Grid architecture optimized fluidly for counter monitor terminals, operational tablets, or handheld staff smartphones.
